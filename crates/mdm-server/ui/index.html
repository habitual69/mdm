Installation Guide

How to load the mDm extension in Chromium & Firefox browsers
1
Open Extension Manager

Click Add to Browser above or go to chrome://extensions (Chrome/Brave), edge://extensions (Edge), or about:addons (Firefox).

2
Enable Developer Mode

Toggle the Developer mode switch in the upper-right corner of the browser's extension manager.

3
Load Unpacked Extension

Click Load unpacked and select the mDm extension folder (or drag and drop the folder directly into the browser window).

4
Pin & Enjoy Fast Downloads

Pin the mDm extension icon to your toolbar. Right-click links or media anytime to Download with mDm instantly!

The extension communicates with the local mDm service on port 3030 via encrypted JSON-RPC. Keep mDm running in the background for automatic capture.

mDm

Media Download Manager v0.1.0-alpha.1

A high-performance, open-source download accelerator and stream extractor engineered with Rust, aria2, yt-dlp, and Tauri.

About This Project

Modern architecture built to redefine media and file downloads

mDm (Media Download Manager) is a powerful, modern replacement for legacy download tools like IDM. Engineered with high concurrency and efficiency in mind, mDm combines segmented multi-connection acceleration with deep media intelligence.

Multi-Connection Acceleration

Splits large HTTP/HTTPS downloads into up to 16 parallel segments via aria2 to maximize available bandwidth.

Universal Media Extraction

Extracts 4K/1080p video, audio tracks, and playlists from YouTube, Twitter/X, Reddit, TikTok, and 1,000+ sites via yt-dlp.

Browser Extension Integration

IDM-style video grabber bar on web pages, smart file download interceptor, and instant download confirmation dialog.

BitTorrent & Magnets

Native torrent metadata probing, selective file downloading, and automatic DHT/PEX peer discovery.

Technical Specifications

Underlying engine and runtime components
Core Engine: Rust (Tokio, Axum, SQLite)
Desktop Shell: Tauri v2 • WebView2 (Win32)
Segmented Downloader: aria2c (Bundled v1.37.0)
Media Parser: yt-dlp (Auto-Updatable)
Media Processor: FFmpeg & FFprobe
Daemon Endpoint: 127.0.0.1:5757
